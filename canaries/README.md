## 三档验证纪律

| 档 | 触发 | 内容 |
|---|---|---|
| 轻 | 每次知识库/签名变更 | `check_signature.py` 回放其声称来源的历史日志，命中才算数 |
| 中 | 结构性改动（flow、判据详表级） | 受影响段落重放 + 一段冒烟；不跑全量 |
| 重 | vllm-ascend / CANN 版本升级；真实 Day0 前 | 金丝雀全段过一遍，顺手校准签名正则 |

升版是免费的回归集：签名库自述「grep 文案随版本漂移」，每次升级必须走重档。
